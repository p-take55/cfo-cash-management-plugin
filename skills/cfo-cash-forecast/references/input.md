# 日付別資金計算

Python 3.10以上、標準ライブラリのみ。入力ファイルを読み、結果JSONを標準出力へ返す。ネットワーク・口座操作・元ファイル更新はしない。

Skillの場所を基準に `python3 scripts/forecast.py INPUT.json` を実行する。

```json
{
  "currency": "JPY",
  "start": "2026-12-01",
  "end": "2026-12-14",
  "opening": "300000",
  "floor": "100000",
  "events": [
    {"id": "cost-1", "date": "2026-12-04", "kind": "out", "amount": "180000", "currency": "JPY", "status": "scheduled", "source": "架空の支払予定1"},
    {"id": "sale-1", "date": "2026-12-08", "kind": "in", "amount": "200000", "currency": "JPY", "status": "scheduled", "source": "架空の入金予定1"},
    {"id": "cost-2", "date": "2026-12-11", "kind": "out", "amount": "250000", "currency": "JPY", "status": "scheduled", "source": "架空の支払予定2"}
  ]
}
```

架空例。終了残高70,000円、本人指定下限との差30,000円。入金日を12月18日へ移した場合は期間外として表示され、終了残高−130,000円になる。

- `opening` は `start` 当日の入出金を含む前の利用可能残高。対象口座・事業を先に統一する。
- `start` / `end` は両端を含む。日付不明の予定は別に残し、この計算結果が完全とは扱わない。
- 金額は十進の文字列または整数。小数は文字列で渡す。空・不明・無限・NaN、負の明細金額、異なる通貨、重複IDは拒否する。精度範囲は24桁、小数8桁まで。
- `floor` の省略・nullは未設定。ゼロ割れと本人指定の下限割れを別々に返す。
- `status` は `actual`（実績）/ `scheduled`（予定）/ `assumed`（仮定）。仮定も入力したケースの計算には含むがID一覧を返す。基本予測へ混ぜてよいかは実行前に判断する。
- 同日の入金・出金の順序は計算しない。両方ある日は注意対象として返す。日末が正でも日中の支払能力の証明にはならない。
- 対象外期間の明細は除外IDへ記録する。開始日より前の取引を開始残高へ自動加算しない。
- 支払・入金の網羅性、口座間振替の除外、カード明細の二重計上、元資料との照合は実行前に確認する。
- 計算結果の `minimum_balance` は開始残高と各日末の最小値。入出金がない日も残高は繰り越される。
