# 資金繰り管理

資金の見通し、前回からの変化、条件ごとの比較、足りないときの打ち手の 4 つの Skill。日ごとの資金を計算する Python スクリプト付き。

[CFO](https://github.com/p-take55/aachat-cfo) の Skill のうち、資金繰り管理にあたるものを Plugin にまとめたものです。単独で入れても使えます。

## 同梱の Skill

| Skill | すること |
|---|---|
| `cfo-cash-forecast` | いつ資金が足りなくなるかを計算する |
| `cfo-cash-monitor` | 前回から資金の見通しがどう変わったかを調べる |
| `cfo-cash-scenarios` | 売上が届かないときや入金が遅れたときの資金を比べる |
| `cfo-cash-actions` | 資金が足りないときの打ち手を並べる |

## 使うときに

数字の元になる資料、扱う事業・期間・通貨、守りたい残高や使える予算を、要る範囲で渡してください。手元の資料からでも、使える接続からでも始められます。

同梱の Python スクリプトを使うときは Python 3.10 以上が要ります（標準ライブラリだけを使います）。

- 実績・予定・仮定、利益と入出金、本人の工数を分けて扱い、分からない金額をゼロで埋めません。
- 外部サービスとつなぐ設定（MCP・認証）、定期実行、通知は同梱していません。
- 送金・注文・支払・借入・投資の取引・税の申告・契約の変更・外への送信はしません。この Plugin を入れたことを、それらの許可とは受け取りません。
